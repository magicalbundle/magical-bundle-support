## Pinned reporting rules

1. Search the forum and GitHub Issues before posting.
2. Use one report per problem.
3. Include product, Resolve, and macOS versions.
4. Include exact reproduction steps and the sanitized Activity Log.
5. Never post license keys, emails, private paths, or client media.
6. Confirmed reports are mirrored to GitHub Issues.
7. A report does not guarantee a particular fix or release date.

## Automation boundary

The Discord-to-GitHub bridge may create and update support tickets. It must not
modify plugin source code, publish releases, deactivate licenses, or expose
private Discord messages. Product changes require explicit owner approval.
