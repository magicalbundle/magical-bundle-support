# Security policy

Please do not disclose license keys, license-bypass methods, private customer
data, or exploitable security details in a public GitHub issue or Discord
channel.

For the private preview, contact a Magical Bundle administrator in Discord and
request a private security ticket. Include only the minimum information needed
to reproduce the problem. Never attach a real license key; use the last four
characters only when identification is necessary.

Public bug reports containing secrets or private data may be hidden or removed.
