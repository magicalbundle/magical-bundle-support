# Magical Clipper Support

Public issue tracker for **Magical Clipper Free** and **Magical Clipper Pro**.

This repository contains support forms and public documentation only. It does
not contain the Magical Clipper source code, license-validation code, customer
license keys, or release packages.

## Report a problem / Reportar un problema

Use the **Bug report / Reporte de error** issue form and complete every required
field. Before posting, remove license keys, email addresses, private project
names, client media, and personal filesystem paths from screenshots and logs.

Community discussion takes place in the Magical Bundle Discord. Confirmed bugs
are tracked here so they are searchable and do not get lost in chat.

## What happens next / Que sucede despues

1. A report is reviewed and labelled.
2. The issue is reproduced when enough information is available.
3. A proposed fix and its risk are presented to the product owner.
4. Code is changed only after owner approval.
5. The fix is tested before a new package is prepared.

Opening an issue does not automatically authorize a product change or release.

## Security and licensing

Do not publish suspected license bypasses, license keys, or security details in
a public issue. Follow the private reporting instructions in [SECURITY.md](SECURITY.md).
